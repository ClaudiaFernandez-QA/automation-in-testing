# 📝 Proyecto de QA - Automation in Testing

Proyecto **en desarrollo** que tiene como objetivo **practicar el análisis de funcionalidades, la documentación de pruebas funcionales, el reporte de bugs y la automatización de pruebas UI y API** sobre el sitio **Shady Meadows B&B**.

Incluye documentación de:

✅ User Stories  
✅ Criterios de Aceptación  
✅ Casos de Prueba  
✅ Reportes de Bugs encontrados
